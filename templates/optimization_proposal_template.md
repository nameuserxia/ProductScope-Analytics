# 优化建议模板

## 优化建议标题

用一句话说明优化方向，例如：降低新手引导强制时长，提高首局完成率和 D1 留存。

## 当前问题

- 问题描述：（用户在哪里遇到阻力）
- 发生场景：（新手、日常、付费、广告、活动、社交）
- 问题严重程度：（高 / 中 / 低）

## 问题证据

可使用以下证据类型：

- 体验观察：路径复杂、反馈弱、等待长、文案不清。
- 漏斗数据：某一步转化明显低于前一步。
- 留存数据：参与 / 未参与模块用户留存差异。
- 分群数据：某渠道、设备、等级、付费层用户异常。
- 用户反馈：评论、客服、问卷、访谈。
- 竞品对比：同类产品在该模块的设计更顺畅。

## 影响用户

| 用户群体 | 影响方式 | 可能后果 |
| --- | --- | --- |
| 新用户 | 理解成本升高 | 首日流失 |
| 活跃用户 | 日常目标疲劳 | 活跃下降 |
| 付费用户 | 价值感不足 | 复购下降 |

## 影响指标

| 指标 | 当前表现 | 预期影响 | 优先级 |
| --- | --- | --- | --- |
| （指标名） | （当前假设或数据） | （提升 / 降低 / 稳定） | （高 / 中 / 低） |

## 潜在风险

- 是否可能降低收入？
- 是否可能造成资源通胀？
- 是否可能让高价值用户不满？
- 是否可能影响其他模块？

## A/B Test 验证方案

| 项目 | 设计 |
| --- | --- |
| 实验对象 | （新用户 / 老用户 / 指定等级 / 指定渠道） |
| 对照组 | （保持原方案） |
| 实验组 | （使用新方案） |
| 核心指标 | （例如 D1 留存、任务完成率、付费率） |
| 护栏指标 | （例如投诉率、广告后退出率、ARPU） |
| 实验周期 | （至少覆盖核心留存周期） |
| 样本要求 | （保证样本足够，不混入大版本干扰） |

## 成功判断标准

- 核心指标提升达到预设阈值。
- 护栏指标没有明显恶化。
- 不同用户分层下收益稳定，不只对单一小群体有效。
- 若商业化指标短期下降，需要证明长期留存或 LTV 有补偿空间。

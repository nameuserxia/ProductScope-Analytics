# 功能模块拆解模板

## 模块名称

（例如：新手引导、主线关卡、日常任务、成长系统、商城、广告激励、排行榜、公会、活动中心）

## 模块入口

- 入口位置：（首页按钮 / 关卡结算页 / 弹窗 / 任务栏 / 活动页）
- 触发条件：（等级、关卡、登录天数、行为完成、付费状态）
- 入口优先级：（强引导 / 常驻 / 弱提示 / 限时曝光）

## 模块功能描述

用 2 到 4 句话描述模块让用户完成什么行为，以及系统给出什么反馈。

## 用户侧作用

- 对新用户：（降低理解成本、提供首个目标、建立信任）
- 对活跃用户：（提供日常目标、减少无事可做）
- 对付费用户：（提供效率、稀缺、身份或进度价值）
- 对流失风险用户：（提供召回理由、降低回归门槛）

## 产品侧作用

- 留存作用：（如何提高 D1 / D3 / D7 / D30）
- 活跃作用：（如何提升 DAU、启动次数、在线时长、任务参与）
- 付费作用：（如何创造付费场景、提高转化或复购）
- 广告作用：（如何增加激励视频曝光和广告价值）
- 社交传播作用：（如何促进邀请、分享、排行榜竞争或组队）

## 设计动机推测

- 产品为什么要设计这个模块？
- 它解决了哪个用户阶段的问题？
- 它和商业目标之间的关系是什么？

## 设计优点

- 用户体验层面：（是否清晰、低门槛、有反馈）
- 数据增长层面：（是否能带动留存、活跃、转化）
- 商业化层面：（是否能自然承接付费或广告）

## 潜在问题

- 用户理解问题：（信息过载、规则复杂、入口隐藏）
- 体验问题：（强迫感、重复感、反馈弱、等待长）
- 商业化问题：（付费压迫、广告打断、资源失衡）
- 数据问题：（指标提升可能伴随长期留存下降）

## 可优化方向

- 信息架构优化：（入口、层级、文案、提示）
- 节奏优化：（触发时机、频率、冷却、阶段差异）
- 奖励优化：（奖励价值、随机性、保底、成长匹配）
- 分层优化：（新手、活跃、沉默、付费用户不同策略）
- 实验验证：（A/B Test、漏斗分析、留存分群）

## 关键指标

| 指标 | 定义 | 计算口径 | 业务意义 | 异常时可能原因 | 验证方法 |
| --- | --- | --- | --- | --- | --- |
| 模块曝光率 | 看到模块入口的用户占比 | 模块曝光 UV / 活跃 UV | 判断入口覆盖能力 | 入口过深、触发条件过严 | 分渠道、等级、设备查看曝光差异 |
| 模块点击率 | 点击模块的用户占比 | 模块点击 UV / 模块曝光 UV | 判断吸引力和理解度 | 文案弱、奖励不清、入口视觉弱 | A/B 测试入口文案和奖励展示 |
| 模块完成率 | 完成模块核心行为的用户占比 | 完成 UV / 进入 UV | 判断流程阻力 | 难度高、流程长、奖励不足 | 漏斗拆解每一步流失 |

## 数据分析方法

- 漏斗分析：曝光 -> 点击 -> 进入 -> 完成 -> 领奖 -> 次日回访。
- 留存分群：参与模块用户 vs 未参与模块用户的 D1 / D7 / D30 留存。
- 付费分群：模块参与频次与付费率、ARPPU、复购率的关系。
- A/B Test：调整入口、奖励、触发时机或文案，观察目标指标和护栏指标。
- 护栏指标：广告投诉率、关卡失败率、负反馈率、流失率、付费退款率。

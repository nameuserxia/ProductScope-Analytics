# 扩展到其他互联网产品

这个框架的底层逻辑是“用户需求 -> 核心行为 -> 功能模块 -> 指标体系 -> 耦合关系 -> 优化实验”。因此可以从游戏扩展到其他互联网产品。

## 电商产品

### 核心行为

浏览商品 -> 搜索 / 推荐 -> 加购 -> 下单 -> 支付 -> 履约 -> 复购。

### 模块替换

| 游戏模块 | 电商对应模块 |
| --- | --- |
| 新手引导 | 新用户权益、首单引导 |
| 主线关卡 | 商品浏览、搜索、推荐 |
| 任务系统 | 签到、会员任务、优惠券任务 |
| 成长系统 | 会员等级、积分体系 |
| 商城 | 商品详情页、购物车、结算页 |
| 活动系统 | 大促、秒杀、满减 |
| 社交系统 | 分享、拼团、评价、种草 |

### 重点指标

- 转化：商品点击率、加购率、下单率、支付成功率。
- 留存：复购率、月活、会员留存。
- 商业化：GMV、客单价、毛利、券后转化。
- 体验：搜索无结果率、退款率、履约时效。

## 出行产品

### 核心行为

输入目的地 -> 查看价格和等待时间 -> 下单 -> 等车 -> 行程 -> 支付 -> 评价。

### 重点模块

- 首页定位和目的地输入。
- 价格预估。
- 司机匹配。
- 等待体验。
- 支付和发票。
- 会员和优惠券。
- 安全保障。

### 重点指标

- 下单转化率、应答率、取消率、等待时长。
- 行程完成率、投诉率、安全事件率。
- 优惠券使用率、复购率、峰谷供需平衡。

## 社区产品

### 核心行为

浏览内容 -> 互动 -> 关注 -> 发布 -> 形成关系链 -> 回访。

### 重点模块

- 推荐流。
- 发布器。
- 评论和点赞。
- 关注关系。
- 话题和活动。
- 创作者成长。
- 内容审核。

### 重点指标

- 内容消费：曝光、点击、阅读完成率、播放完成率。
- 互动：点赞率、评论率、转发率、关注率。
- 生产：发布率、创作者留存、优质内容占比。
- 社区健康：举报率、审核通过率、负反馈率。

## 工具类产品

### 核心行为

打开工具 -> 创建任务 -> 编辑 / 处理 -> 保存 / 导出 -> 分享 / 复用。

### 重点模块

- 首次上手。
- 核心编辑器。
- 模板库。
- 文件管理。
- 导出和分享。
- 订阅和高级能力。

### 重点指标

- 激活率、首次任务完成率、功能使用率。
- 模板使用率、导出率、协作邀请率。
- 订阅转化率、续费率、功能触达率。

## 迁移时保留的分析问题

无论产品类型如何变化，都保留以下问题：

- 这个模块为什么存在？
- 它服务哪类用户？
- 它影响什么核心指标？
- 它和哪些模块耦合？
- 指标异常可能说明什么？
- 优化后如何验证收益？
- 是否存在短期收益和长期体验之间的冲突？
